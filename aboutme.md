# About Me

Hi, I'm **Ankit**, a software developer and builder focused on turning ideas into practical software systems.

I enjoy working across the stack—from modern web applications and APIs to authentication infrastructure, native desktop software, mobile applications, Linux systems, and AI-powered tools. My GitHub projects reflect a strong interest in understanding how software works beneath the surface rather than only assembling frameworks.

## What I Build

- **Full-stack applications** with Next.js, React, TypeScript, Python, and FastAPI
- **Backend systems and APIs** with PostgreSQL, Drizzle/SQLModel, WebSockets, background jobs, and cloud storage
- **Authentication infrastructure**, including OAuth 2.0, Better Auth, session management, RBAC, and secure application flows
- **Native software** with C/C++, GTK, CMake, POSIX networking, and Linux tooling
- **Mobile applications** with React Native/Expo and Kotlin with Jetpack Compose
- **Linux systems and operating-system projects**, including custom distributions, Linux From Scratch, musl, and lightweight system tooling
- **AI-enabled applications** and experiments integrating LLM APIs and developer workflows
- **Geospatial software**, including APIs and tools around digital addressing and location data

## Projects & Areas of Interest

### BlazeNeuro
A recurring theme across my work is **BlazeNeuro**—an ecosystem of software projects exploring developer infrastructure, operating systems, authentication, and application platforms.

### VidyaSchool
I have been building **VidyaSchool**, a multi-platform school management ecosystem combining a Next.js web portal, FastAPI backend, C++/GTK desktop client, and React Native/Kotlin mobile applications. The system includes authentication, RBAC, real-time communication, payments, attendance, library management, document sharing, QR-based authentication, and AI-assisted features.

### Authentication & Developer Infrastructure
I have experimented extensively with authentication systems, including custom OAuth 2.0 flows, multi-provider login, encrypted session/data handling, developer portals, application management, and security-focused API design.

### Linux & Systems Programming
I am particularly interested in systems programming and operating-system internals. My repositories include experiments with custom Linux distributions, Linux From Scratch, musl libc, S6, custom C/C++ desktop tooling, and a BlazeNeuro operating-system project.

### Native Developer Tools
Projects such as **CodeE** explore building developer tools at the native level—for example, a VS Code-like text editor using C++ and GTK with syntax highlighting, tabs, file handling, and editor functionality.

### Geospatial & Location Technology
I have also worked with geospatial concepts and digital addressing, including a DIGIPIN-related Node.js API project for encoding and decoding geographic coordinates.

## Engineering Philosophy

I like learning by building. When I encounter a technology that interests me, I prefer to prototype it, understand its internals, and then use that knowledge in a larger system.

I am especially interested in the boundary between **application development and systems engineering**—how authentication, networking, databases, operating systems, native clients, and cloud infrastructure fit together to create reliable products.
